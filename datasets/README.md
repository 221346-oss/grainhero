## Part 1 — Datasets Already In This Repo

### Synthetic Training Data (`training-synthetic/`)

All 5 CSVs were generated by [`farmHomeBackend-main/ml/generate_per_grain.py`](../farmHomeBackend-main/ml/generate_per_grain.py).

**Schema (all 5 files):**

| Column           | Type   | Range              | Notes                        |
| ---------------- | ------ | ------------------ | ---------------------------- |
| `Temperature`    | float  | 15–45°C            | Ambient + grain temperature  |
| `Humidity`       | float  | 20–95%             | Relative humidity            |
| `Storage_Days`   | int    | 0–365              | Days since intake            |
| `Airflow`        | float  | 0.0–1.0            | Fan speed as fraction        |
| `Dew_Point`      | float  | 5–35°C             | Computed: T - ((100-RH)/5)   |
| `Ambient_Light`  | float  | 0–100%             | LDR reading                  |
| `Pest_Presence`  | float  | 0.0–1.0            | **Always 0.0** — placeholder |
| `Grain_Moisture` | float  | 8–25%              | Soil probe mapped to grain   |
| `Rainfall`       | float  | 0–50mm             | **Always 0.0** — placeholder |
| `Spoilage_Risk`  | string | Safe/Risky/Spoiled | **Label (target variable)**  |

**Label distribution (approximate, per file):**

| Label   | % of rows |
| ------- | --------- |
| Safe    | ~50%      |
| Risky   | ~30%      |
| Spoiled | ~20%      |

> ⚠️ **Critical limitation**: Labels are derived from mathematical rules in the generator, not real grain inspections. Expected real-world ML accuracy: **70–85%**, not the 97–99% synthetic test figures.

#### Dataset B: Open-Meteo Historical Weather (No Account Needed)

| Field          | Value                                                                                                           |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| **URL**        | https://api.open-meteo.com/v1/forecast                                                                          |
| **Format**     | JSON API (convert to CSV)                                                                                       |
| **License**    | CC BY 4.0 (free, unlimited)                                                                                     |
| **Features**   | Temperature, humidity, precipitation, wind — hourly                                                             |
| **Use**        | Provides real `Rainfall` + `outside_temp` + `outside_humidity` for the ML feature vector and aeration decisions |
| **How to use** | See download script below                                                                                       |

**Download script for Lahore weather history (copy-paste in Python):**

```python
import requests, csv, json
from datetime import datetime, timedelta

url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 31.5497, "longitude": 74.3436,  # Lahore
    "hourly": "temperature_2m,relativehumidity_2m,precipitation,windspeed_10m",
    "start_date": "2024-01-01", "end_date": "2025-12-31",
    "timezone": "Asia/Karachi"
}
r = requests.get(url, params=params)
data = r.json()["hourly"]
rows = list(zip(data["time"], data["temperature_2m"],
                data["relativehumidity_2m"], data["precipitation"]))
with open("DATASETS/external-catalog/lahore_weather_2024_2025.csv","w",newline="") as f:
    w = csv.writer(f)
    w.writerow(["timestamp","temperature","humidity","rainfall_mm"])
    w.writerows(rows)
print(f"Saved {len(rows)} hourly records")
```
